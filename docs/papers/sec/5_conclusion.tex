\section{Conclusion}
In this work, we introduced RestoraMind, an LMM-powered agent that jointly reasons about degradations and adaptively utilizes restoration tools within a sequential decision-making framework. To achieve this, RestoraMind is trained end-to-end through reinforcement learning guided by a composite reward that integrates both quality improvement and degradation reasoning. In addition, we incorporate image statistics as informative priors to guide the agent in selecting the most suitable tool among multiple candidates designed for the same degradation type. Extensive experiments demonstrate that RestoraMind substantially outperforms prior state-of-the-art approaches while reducing tool invocations to a near-linear scale, showcasing both effectiveness and efficiency for real-world image restoration.
