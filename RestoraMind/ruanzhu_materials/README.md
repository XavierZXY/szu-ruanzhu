## 重新生成

材料全部由脚本从源码生成，改动源码后按顺序重跑即可（需要 reportlab、python-docx、pymupdf，可装在独立虚拟环境）：

```bash
python ruanzhu_materials/make_figures.py        # 示意图与离线演示图
python ruanzhu_materials/crop_paper_figures.py  # 论文定性图：只保留输入与本方法输出
python ruanzhu_materials/collect_results.py     # 批量评估与训练曲线，写入 results.json
python ruanzhu_materials/build_source_pdf.py    # 源程序 PDF
python ruanzhu_materials/build_manual.py        # 说明书 PDF + Word
```

说明书中的工具表、接口参考、测试清单由源码自动提取，离线评估数值来自 `results.json`。
第 7 章的论文实验数据（定量对比表、工具调用统计）与论文图片（动机对比、流程示例、三组定性对比、工具使用分布）取自 `docs/papers`，表格数值已逐项与论文 `4_experiments.tex` 核对；论文中效率表的 RestoraMind 一行尚为占位符，说明书未引用。
